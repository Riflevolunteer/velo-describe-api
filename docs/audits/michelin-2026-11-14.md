## Actual transcription error

Spec **15681**, 1987 US Mont Cenis:

- Previous DB/CSV value: `Michelin "Hi Lite Pro", 700x70C [?]`.
- Original scan, model p.5: `700x20C` below the Michelin Hi Lite Pro name.
- Applied DB/CSV value: `Michelin "Hi Lite Pro", 700x20C`.

The 1987 US Triathlon p.6 independently prints `700x19` and Michelin Hi-lite pro.
Both keep their existing 6836 links. The matching Tyres cell in
`bike_specs/1987_peugeot_us_spec.csv` was backed up and repaired with an RFC-4180
CSV parser; a parsed comparison confirmed exactly one cell changed. Generation
showed the corrected quoted spelling needed an override, so the erroneous
700x70C override was replaced with a 1987 Mont Cenis-scoped 700x20C mapping.
The full generation comparison then preserved all component links. Correcting
the DB alone would have allowed the old CSV text to return as a separate spec.

## Pages inspected

The [evidence manifest](michelin-2026-11-14-evidence.json) retains exact image URLs
and SHA-256 hashes. Source IDs already exist; no new source row is proposed.

1. **Peugeot FR, attributed 1986, source 309:** technical table images 6 and 7
   on the [catalogue page](https://labibleduvelocataloguespeugeot1.blogspot.com/p/peugeot-1986.html).
   Image 6: PH11 has Super Elan; the footnote identifies Super Elan/BIB TS20 as
   Michelin. Image 7: PH501, PH513 and PGN10M have BIB TS20; the GOLD footnote says
   the equipment is the same as PGN10M except the finish.

   current Blogger image positions 30/31 on the same page. Mont Cenis: Hi Lite
   Pro 700 x 20C. Triathlon and Ventoux: Hi Lite Road 700 x 23C. Tourmalet: Hi
   Lite Road 27 x 1-1/8. This is explicit model/size evidence for keeping the
   Tourmalet link; it does not transfer 700C weights to the 27-inch version.
3. **Peugeot FR, attributed 1987, source 311:**
   [Specifications 1](https://www.bikeboompeugeot.com/Brochures%20France/Peugeot%201987%20France%20Brochure/Peugeot_1987_French_Brochure_Specifications1_BikeBoomPeugeot.JPG)

   All 11 flagged Road rows name Hi-lite Road 700 x 20C. Aubisque PE10DW and
   PE10LW name Michelin Super Elan 700 x 23. The [archive's dating explanation](https://www.bikeboompeugeot.com/Brochures%20France/Peugeot%201987%20France%20Brochure/Peugeot%201987%20France%20Brochures.htm)
   explicitly calls the mid-1980s French series undated; preserve this caveat.
4. **Peugeot US 1987, source 312:**
   [Mont Cenis p.5](https://www.bikeboompeugeot.com/Brochures%20USA/Peugeot%201987%20USA%20Brochure/Peugeot%201987%20USA%20Brochure%20Page%205.jpg)

5. **Peugeot NL 1989, source 320:** printed p.30, current Blogger image 29 on
