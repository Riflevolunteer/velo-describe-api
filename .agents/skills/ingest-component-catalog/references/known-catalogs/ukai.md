# Ukai catalogs processed so far

## Ukai Rims, Yanagihara Industrial Co., Ltd. (July 1980) — bmxmuseum.com reference 7214, data_source id 354

- Source: https://bmxmuseum.com/reference/7214 ("Ukai Rims", submitted by
  monkist 2024). Five `_blowup.jpg` images at 1200x900 (IMG_7697-7701):
  cover, two-page range spread (17 models), packing list (model, size,
  pcs, cft, net/gross kg), back cover. Dated by the back-cover print code
  "S55.7. 2,000" = Showa 55, July 1980, 2,000 copies.
- First Ukai catalogue. The DB had six bare velobase rows (brand 519,
  Rims): 5192-5197.
- Approx. weights = packing-list net kg / pcs, written into descriptions
  as "approx.". "C-p finish" = chrome-plated steel.
- Part numbers shared with Araya for the same model names (araya.md,
  source 152): 16A(1) No. 3945/3948/4087, 16B 3955/3956, 20A 4093/4094 —
  apparently a common Japanese rim numbering, so a bare "No. 39xx/40xx"
  doesn't identify the brand.
- Inserted (15 rows, 10457-10471, UUID source_id, 1980-1980, one per
  catalogue column): Ukai Model 1, 5, 5R, 10, 7A, 3A (steel); 17(1),
  17(2), 17(3) (steel Endrick balloon; 17(3) dimpled holes); 16A(1),
  16A(2), 16A(5), 16B, 7C, Beach Cycle (alloy). The 16A and 17 widths are
  kept as separate rows (Araya merged its 16A widths into one); their
  search_text collapses to "Ukai Model 16A" / "Ukai Model 17".
- Retitled: 5192 "Ukai (700x25c)" (velobase, 450g Actual) -> "Ukai Model
  20A" (20A 700x25C weighs approx. 441g by the packing list), years NULL
  -> 1980, source_ref 1 -> 354; measured 450g kept in the description.
- Not inserted: Model 105 (steel 1.20x17/18/19 moped rims, No. 3968-3970).
- Unresolved: 16A(5) part numbers illegible at 1200px (40xx; 700x28C and
  27x1-1/8); No. 4083 printed for both the 7C 24x1.75 and the Beach Cycle
  24x2.125; Beach Cycle's first size reads 28x2.125 in the spec column but
  26x2.125 in the packing list (26 used). 5193 "alloy, 27 x 1-1/8" 610g
  could be 16A(5) 27x1-1/8 but that weighs approx. 520g, so left;
  5194/5195 generic steel placeholders and 5196 21A / 5197 CR-700 (not in
  this catalogue) left unchanged.
