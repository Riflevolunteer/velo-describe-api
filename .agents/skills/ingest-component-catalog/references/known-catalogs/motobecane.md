## Motobécane dealer spare parts catalogue, "Gamme 1985, Série course, Pays France", édition mai 1985 (Velo Vintage à Gogo t26128) — data_source 381

- Source: velovintageagogo.com/t26128 ("extrait catalogue officiel
  MOTOBECANE Agent séries courses mai 1985", poster MAFAC 2000), 40 scans
  at `https://i.servimg.com/u/f70/20/23/69/69/<id>.jpg`, ids 20231584-20231631
  with gaps; 20231611 / 20231612 are byte-identical duplicates, so 38 unique
  pages. Scans are posted out of order; printed pp. 1-36 plus contents and
  an alphabetical index. Dated "édition du: Mai 1985" on the table pages.
- Bike models (grid columns): BC 111, BC 121 (Sprint / Super Sprint),
  C 152 / C 152 da (MBK Trainer), C 222, C 232 / C 232 da (Mirage, Mirage
  18), C 332 (Super Mirage), C 442 (Grand Record, Reynolds 501), C 552
  (Team Champion, Columbus). No Motobécane bikes of 1985 are in the DB, so
  the grids were not used for links.
- Contents (printed pages): frames / colours 1-4, bar tape 6, bars / stems
  7-8 (Atax PSC 75 / 90, ASC 75 / 90 / 105, CTA 90 / 110, dural Ø25),
  chainset index 9, steel cottered 10, Nervar 2010-2011 11, Thun Beta II 12,
  Nervar 2023-3023 13, Nervar 2020-3020 14, Stronglight 103 15, pedals 16
  (steel BSC, dural reflectorised, Maillard RA 500 dural BSC 9/16" x 20
  without reflectors on C 222-C 442, Sakae SP100-BL on C 552), derailleurs /
  shifters 17-21 (Huret Club 1000, Rival, Rider, Eco; Simplex SJA 222,
  SX 610/SP, SLJ 6600 levers), wheels / hubs 22-25 (Atom 36T, Atom Sport QR,
  Maillard 700 PF, Hélicomatic Sport 36T QR), rims / tyres 26 (Rigida
  13/20, Super Champion Arc-en-ciel, Hutchinson HP 22-622, Michelin Elan
  700 x 23, Wolber Strada 335 g, Hutchinson Corsa Senior 315 g),
  freewheels / chain 27-29 (5-speed BSC 14-26; Maillard 700 Helicomatic
  SHA-SHF sprockets, 6-speed 99546 / 99739; Maillard 700 Compact MS / MT /
  MB / MR / MA sprockets, French 34.7 x 1 or BSC body, 6-speed BSC 99475;
  Sedisport 114 links), brakes / levers 30-33 (Weinmann 405 / 500 / 501,
  LAM drilled race levers, Weinmann 144-1), cables 34, saddles / posts 35
  (Atax 25.4, Sakae CT-P5 26.6), pumps / mudguards 36. Headsets (Bardon,
  Thun, Motobécane) on an unnumbered forks page.
- Nervar: 2020-3020 (p. 14) 5-arm cotterless double, axle 117 mm, cranks
  170 mm 14 x 1.25 (98839 / 99470) or 9/16" x 20 (99944 / 99943), outer
  rings 46 / 48 / 50 ajouré / 52 ajouré, inner 38-45, set 89778 "ensemble
  3020 Lg 170 BSC 42x52". 2023-3023 triple (p. 13): axle 121, the drilled
  50 / 52 outer rings are marked "3023", so 30xx = drilled-ring version
  (inference). 2010-2011 (p. 11): axle 117, dural 46-52 / 36-46 or steel
  46-53 / 36-42 rings; 2010 vs 2011 distinction not printed.
- Added (source_ref 381): 10980 Nervar 2020 (1985-87), 10981 Nervar 3020
