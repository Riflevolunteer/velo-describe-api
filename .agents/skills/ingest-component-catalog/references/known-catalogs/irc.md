# IRC catalogues

## Polish IRC catalogue, 1999 — reviewed 2026-11-18

Source: [IRC Polish catalogue](https://bikalog.org/api/view/IRC/1999/irc99.pdf),
four PDF pages, each composed of catalogue panels. The cover explicitly prints
`KATALOG 1999` and shows an SSC Wrocław, ul. Traugutta 81a imprint. The final
panel names IRC Japan and INOAC International in Nagoya. The copy is Polish;
SSC is a local contact on this copy, but the scan does not explicitly establish
whether it published, translated or distributed it. A [1997 Cannondale catalogue](https://vintagecannondale.com/year/1997/1997e.pdf)
independently lists S.S.C. Poland at that address as its Polish representative;
this establishes a contemporaneous bicycle-trade contact, not SSC's precise
role for IRC. Treat the printed 1999 as catalogue/model-year availability,
not an independently verified printing date or production boundary. Source
**450** now registers this catalogue; IRC is brand 647 and has a Tyres association.

### Pre-load reconciliation

Live IRC brand inventory contains ten rows. **10220 Cross Country** already
matches the 1999 700 x 35C / 395 g listing and covers 1999. **6818 Paperlite
Plus** covers 1999, but describes 700 x 23 as 175 g; this catalogue states
175 g for 700 x 20C and 195 g for 700 x 23C. The cited [Guida '96 scan 20 / p.123](https://www.disraeligears.co.uk/site/00_main_images/la_bicicletta_guida_96_-_componenti_scan_20_main_image.jpg)
indeed prints 175 g for 700 x 23 Plus, with 220 tpi continuing at the top of
the next column. Preserve the 1996 and 1999 specifications as conflicting
edition-specific claims; neither source proves which is a misprint. The 1999
page calls Kevlar the bead;
do not silently convert that into a casing material.

**10219 Paperlite Aqua Wire** describes a 66 tpi wire-bead configuration;
this catalogue's Paperlite Aqua is 220 tpi with a Kevlar bead, so it cannot be
treated as the same configuration on name alone. **10529 Paperlite** is a
different unqualified 1996 entry; do not equate it to Plus or Aqua without a
crosswalk. **11359 Triathlon** is the likely 1999 base-model match: both list
127 tpi and 700 x 20/25C and 27 x 1; confirm construction/edition detail
before extending its 1987–1992 range. Its bike specs 1298 and 19699 are linked;
preserve those links and distinguish the 1999 Duro option. None of the other
model names above appears as an IRC row in the live inventory. Reconcile each
model, bead, position and Duro configuration before proposing insertions;
do not infer continuous production or retroactively assign a bike fitment.

This initial inventory and reconciliation made no source, component,
date, bike-link or generator changes. The subsequent approved load and
mapping checks are recorded below.

### Applied and validated — 2026-11-18

source 450 (Polish copy, no unsupported attribution of SSC's role), inserted
33 tyre rows 11568–11600 and applied two guarded updates. The
catalogue attests 1999; the proposed 1999–1999 values do not establish either
production endpoint. New rows are grouped by model/position/bead/configuration:

  XC; Mud Mad front and rear; Blizzard; Metro and Metro Duro; Metrocross and
  Metrocross Duro; Claw Comp; Fiesterra.

  Minute Man Slick; Minute Man; Z-II; Flatlander. Existing Aqua Wire 10219

Updated 6818 description attributes **700 x 23C 175g to Guida '96** and
**195g to 1999**, while the latter also lists 650 x 20C 155g and 700 x 20C

description's Kevlar-casing assertion. Prior 6818 values: source 357,
1996–1999, `Clincher, 700x23; 220 tpi Kevlar casing; directional slick
tread; 175 g.`

For 11359, the 1999 base Triathlon has the same name, 127 tpi and overlapping
700 x 20/25C and 27 x 1 sizes as the earlier row, with a wire bead and oval
profile. This supports treating it as the base model, with a separate Duro.
The update retains 1987 as year_from and extends year_to from 1992
to 1999 as an availability range, not proof of continuous production. It
retains the earlier 265g/125 psi and nylon-casing source record, whose weight
has no specified size, and lists the distinct 1999 weights (26 x 1 215g, 27 x 1 255g,
700 x 20C 245g, 700 x 25C 260g). Previous source 422, 1987–1992, description:
`Racing clincher, oval section, high-tpi nylon casing; 700x20c, 700x25c,
27x1; 265g, 125 psi, 127 tpi.` Restore the old descriptions, dates and sources
if reversing the updates; check links and overrides before removing additions.
