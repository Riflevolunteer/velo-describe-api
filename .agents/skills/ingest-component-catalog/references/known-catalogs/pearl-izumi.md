# Pearl Izumi component evidence

## Flolite saddles — Performance Fall/Winter 1985–86 US, source 462

Brand **723 Pearl Izumi** is distinct from French leather-saddle maker LF Pearl 550.
The retailer explicitly lists three Italian-made numbered Flolite saddles:
**11698 model 100**,**11699 model 200**,**11700 model 300**, all attested 1985–86.
100/200 have smooth black leather covers, Flolite cushioning and listed 456g
weight; 100 is softer than 200. 300 has buffalo leather, forged alloy rails,
tension-adjustment screw and listed 350g weight. The 1984 magazine-test reference
is context for the family, not independently verified dating for all three models.
