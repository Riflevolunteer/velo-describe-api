## Zeus Cyclery Corp. 1982 Catalog (US importer) — disraeligears, 24 pages, data_source id 286

- `data_source` 286, label "Zeus Cyclery Corp. 1982 Catalog (1982)", country US. Source:
  https://www.disraeligears.co.uk/site/zeus_cyclery_corp_-_1982_catalog.html; only page 1 is linked, the rest follow
  `00_main_images/zeus_cyclery_corp_-_1982_catalog_page_NN_main_image.jpg` (01-24, 1560 x 1200). Read 2026-10-28.
  Zeus Cyclery Corp. is the US distributor: the Zeus (Spain), Roto (see roto.md) and REG ranges plus Zeus Supercronos /
  Elan and Cuevas frames. **The year is printed on the cover.**
- **Numbering:** 5-digit refs (13xxx cranks, 2x... derailleurs and levers, 23xxx BBs, 24xxx pedals, 25xxx seat posts,
  26xxx headsets, 27xxx / 37xxx brakes, 28xxx hubs, 29xxx freewheels), replacing the 1977 two-digit Refs. Three series:
  Zeus-2000 (Titanox, Super Earlumin II), Criterium (Earlumin), New Racer (Duralumin S and steel), which **replaced Gran
  Sport** ("replaced Gransport headset / seatpost").
- New vs Catálogo 103 (1977): Zeus-2000 7-speed freewheel 29000, Zeus-2001 braze-on double lever 20900, Z-2000 "Prestige"
  saddle 50501, black / gold anodised Z-2000 finishes, the New Racer series. Drawing / text code clashes: Criterium road
  crank 13110 on p. 6 but 13100 in the drawings (13110 = triple); Z-2000 5-speed freewheel 29150 (p. 12) vs 29100.05
  (drawing); Criterium 5-speed 29250 vs 29200.05.

  Criterium BB, 187 Pista BB (= Criterium track 23130), 4049 / 4052 Z-2000 road / track pedals, 8857 Ref. 80 Z-2000
  hubs, 3653 Criterium hubs, 3168 Z-2000 headset, 3170 Criterium headset, 5946 Criterium seat post. Descriptions on
  4860, 2680, 8853, 8855, 1178, 8858, 4049, 4052 carry the 1982 ref.
- **`year_from` moved earlier to 1982** (Kitching 1984 rows, now attested two years before; old value 1984 on all):
  9363 New Racer front 22800, 9358 New Racer BB 23200, 6336 New Racer shifters 21300, 3655 New Racer hubs 28500, 9364
  Criterium freewheels 29200.
- Descriptions only: 4873 New Racer rear (22300, 12-28T), 1180 New Racer brake (27400), 3167 New Racer headset, 5951 New
  Racer seat post, 4058 New Racer pedals, 2264 / 2265 / 2266 Z-2000 7 / 6 / 5-speed freewheels.

  Track crankset, 50501.00 Z-2000 Prestige saddle.

Old titles: "Zeus Supercronos" (4875, 1182, 3656), "Zeus Supercronos (2-holes)", "Zeus 21000.00 / 21001.00, Supercronos", "Zeus Supercronos (Zeus in Z)", "Zeus 26000.00, Supercronos", "Zeus 23100.00, Supercronos". ## Catálogo Zeus-103 (Abadiano, July 1977) — Reminiscence Part 94, 22 spreads, data_source id 208

- `data_source` 208, label "Catálogo Zeus-103 (1977)". Source:
  http://cyclespeugeot.web.fc2.com/reminiscence/zeus_77.html, JPG spreads
  `catalog/zeus/1977_zeus_cover1-4, cover2-p01, p02-03 ... p40-41.jpg`
  (**720 x 509 px, two pages per image, ~360 px per page**; the site's E-book
  at adjustbook.com is dead, so no larger version; part numbers and most
  weights read, fine print does not). `nc197801.jpg` on the same page is a New
  Cycling (Jan 1978) Japanese advert showing this cover, a dating
  corroboration. Zeus Industrial S.A., Abadiano (Vizcaya); foreword July 1977
  for the 50th anniversary ("Desde 1926"); 44 pages, A4, Spanish and English.
  Three series by material: Zeus-2000 (titanium, Super Earlumin II),
  Criterium (Earlumin, Super Earlumin II), Gran Sport (Duralumin S, Earlumin).
  Index: derailleurs 2-6, chainwheels 7-11, pedals 12-14, seat posts 15,
  saddles and pumps 16, head sets 17, brakes 18-21, hubs 22-27, freewheels
  28-29, fork ends and crowns 30, balls and grease 31, tools 32-36,
  miscellaneous (clothing) 37, gallery 38-39. The Zeus-2001 side-pull brake
  set is introduced here ("Zeus introduce el modelo 2001"). **Reference numbers
  moved since 1973**: Ref. 80 was the Standard hub and is now the Zeus-2000
  hub (80.1 Criterium), Ref. 34 was the Gran Sport cottered BB and is now the
  Gran Sport chainwheel set, Ref. 24 was the Alfa front and is now the Gran Sport
  rear, Ref. 73 was the Super Alfa lever and is now the Criterium lever, Ref. 61 is
  now the Criterium head set (Gran Sport is 62), so rows were matched by model,
  series and weight, not by Ref.
- **Reading correction:** the Criterium chainwheel set Ref. 31 reads 848 g (it
  first looked like 648 g; titanium Zeus-2000 is 698 g so it cannot be lighter),
  which equals the DB's 848 g "quoted weight from Zeus catalog" on 2027.
- Years extended to 1977 (`year_to`, all `source_ref` -> 208): 4860 Zeus 2000
  rear (184 g, Ref. 20 = 185 g), 2686 Gran Sport front (115 g exact, Ref. 28),
  2026 Criterium triple (31.1), 8144 Pista (31.3), 3654 Gran Sport hubs
  (530 g exact, Ref. 81), 3651 Gigante (Ref. 82, 580 g vs 590 g in 1973), 3652
  Pista hubs (Ref. 83), 3653 Criterium hubs (Ref. 80.1, 520 g), 3171 Gran Sport
  head set (Ref. 62, 180 g vs 188 g), 3170 Criterium head set (Ref. 61),
  5947 Gran Sport seat post (310 g exact, Ref. 52), 6392 track cog (83.1).
  Undated rows dated 1977-1977: 2027 Criterium crankset (Ref. 31, 848 g), 2030
  Gran Sport crankset (Ref. 34, 856 g; **a judgement**, the title says
  "w/ Ciclo-Cross Chainguard" and the Ref. 31.2 cyclo-cross set in Catálogo 102
  is single-ring, see the unresolved note under 102), 4049 / 4052 Zeus 2000
  pedals later model (Refs. 43 / 44, 340 / 310 g), 5710 Zeus 2000 saddle (Ref.
  55), 3168 Zeus 2000 head set (Ref. 60). 1178 Zeus 2001 brake `year_from` 1970
  -> **1977** (**a judgement** against the velobase 1970-80: the 1977 catalogue
  introduces the model and Catálogo 102 does not list it). Descriptions only
  (years already cover 1977): 2680 (Ref. 26, 98 g), 2681 (Ref. 27, 106 g),
  184 / 185 (Refs. 32.3 / 32, 175 g), 4056 (Ref. 48, 380 g), 4057 (Ref. 47,
  420 g), 5946 (Ref. 51, 260 g). 26 rows updated in all.
- New (8 rows, 1977-1977): 8853 "Ref. 10, Zeus-2000 double control lever"
  (110 g), 8854 "Ref. 11, Gran Sport single control lever" (65 g; **may overlap
  6334 "Single Lever"**, 45.4 g actual, 1970), 8855 "Ref. 12, Criterium double
  control lever" (115 g), 8856 "Ref. 24, Gran Sport" rear derailleur (225 g;
  4872 v2, 200 g, 1970 is probably an earlier version), 8857 "Ref. 80,
  Zeus-2000 hub set" (titanium, 470 g), 8858 "Ref. 72.1, Zeus-2001 brake
  lever" (106 g), 8859 "Ref. 56, Criterium leather saddle" (380 g), 8860 "Ref.
  57, Gran Sport saddle" (320 g).
- Left alone: the Criterium rear (Ref. 22, 215 g; cannot tell which of 4867 /
  4868 / 4869), the Zeus-2000 chainwheel set (Ref. 30, 698 g; no weight match
  among 2023 / 2024 / 2025), Ref. 33 Criterium BB (188, 270 g exact, nothing to
  change), the 5-speed and 6-speed freewheels (2265 / 2266, weights exact),
  Refs. 71 / 73 / 76 / 79 (1177, 505, 1179, years already cover 1977). The
  Alfa series (2682, 4862, 4863, 4864, 8145, 8147, 1181), Ideale post 8151 and
  the Imperforable tyre 8148 are absent from this catalogue, consistent with
  their 1973 `year_to`. Out of scope: quick releases and axles 85-87, fork

  clothing and bags V1/01-08, the gallery.
- Deleted: none. Bike links on 2681, 3651, 3652, 3654, 4056, 4057 and 5946 are
  unaffected (only years or descriptions changed, and the Zeus Gigante / Pista
  hub overrides point at ids).

## Catálogo Zeus-102 (Abadiano, Enero 1973) — `ZEUS_102.pdf`, 174pp scan, data_source id 105

First formal run of this skill against a Zeus catalogue, though a 1973 Zeus
*bike-spec* CSV (`1973_zeus_spec.csv`, data_source id 33, see the
ingest-bike-specs skill's own `known-catalogs/zeus.md`) was already loaded,
and several `component_detail` rows already carried ad-hoc "Quoted weight
from Zeus catalog" notes (source_ref still generically 1) from someone
reading this or another Zeus catalogue informally before this skill tracked
provenance — those untouched rows still need source_ref migrated to a proper
`data_source` row if their origin is ever pinned down.

Covers: Section 1 bikes (Zeus + budget "Alfa" sub-brand, out of scope itself
but useful for naming), Section 2 "Componentes" (Ref.01–93), Section 5
"Recambios" spares list (R-prefixed, one-line entries), Section 6
clothing/promo (out of scope). Sections 3 (frame/fork sets), 4 (H-prefixed
tools) and the dealer directory are out of scope — no component category.

**Renamed titles** (catalogue's own naming beats velobase; old title kept
here so an older source that used it can still be matched):
- Front Derailleurs 2681 "Zeus Criterium" → "Zeus Criterium 69" (matches the
  rear mech's name; same groupset).
- Front Derailleurs 2682 "Zeus Alfa" → "Zeus Alfa 65" (catalogue's explicit
  model name for this balancín-system front mech, Ref.24).
- Bottom Brackets 187 "Zeus Criterium Track" → "Zeus Pista" (Ref.33.3; also
  moved year_from 1980→1973 since the catalogue proves earlier presence).
- Hubs 3652 "Zeus Gigante Pista" → "Zeus Pista" (catalogue treats Gigante,
  Ref.82, and Pista, Ref.83, as two separate hub tiers, not one compound
  name).
- Pedals 4056 "Zeus Gran Sport  Pista" (double-space velobase garble) →
  "Zeus Pista" (Ref.42 is named plain "ZEUS PISTA" in the catalogue; also
  reassigned group_id 74→250 to the existing Pista tier group).
- Saddles 5708 "Zeus (black suede)" → "Zeus Leather" (catalogue's spares-list
  name, R.510).

**Years extended / first-dated** (component_id: change):
4870 Criterium 69 rear mech year_to 1970→1973; 4863 "Especial Alfa 72" rear
mech year_to 1970→1973; 2682 Alfa 65 front mech year_to 1970→1973; 2028
Criterium crankset year_to 1970→1973; 190 Gran Sport cottered BB year_to
1960→1973; 188 Ref.33 Criterium BB year_to confirmed 1973; 2026 Criterium
triple crankset, 3171 Gran Sport headset, 3651 Gigante road hub, 6392 Alloy
Track Cog, 4864 Alfa Junior rear mech: all NULL→1973 first-dated evidence.

**Description enrichment with despiece/spec detail** (weights, materials,
threading, tooth ranges) added to all of the above plus: 3654 Gran Sport hub,
2265/2266 Zeus-2000 6V/5V freewheels (added comparative marketing data vs
Regina/Shimano), 4057 Gran Sport pedal (consolidated with an existing note
tagged "catalog 101 (1970)" — two different printings, two different
weights, both kept), 5946 Criterium seatpost.

**New rows inserted** (source_ref 105): Cranksets "Zeus Pista" (Ref.31.3,
670g); Chainrings "Zeus Alfa" (Ref.36, Doble Plato Alfa Acero, steel,
46–52T, 410–440g); Hubs "Zeus Standard" (Ref.80, nutted/non-QR, 480g); Brake
Levers "Zeus Super Alfa" (Ref.73, 110g — Brake Levers had no Alfa-branded
lever at all before this); Tyres "Zeus 2000 Imperforable" (R.850, spares
list, 190g — first Zeus row in Tyres).

**Dedupe (2026-10-04, user confirmed, after checking `bike_spec` and
`COMPONENT_OVERRIDES` for links first):**
- Brake Levers: deleted bare duplicate "Zeus 2000" id 503 (no links anywhere),
  kept id 502 (had a year data point, 1970–1970).
- Bottom Brackets: id 186 "Zeus Criterium" (bare, 1970–1980) and id 188 "Zeus
  Ref.33, Criterium" (270g, catalogue-dated 1973) were the same physical BB.
  186 had 2 `bike_spec` links (bike_spec_id 3, 48; value "Zeus Criterium
  (E)") and no `COMPONENT_OVERRIDES` reference; 188 had neither but carried
  the richer catalogue data. Moved both bike_spec rows to 188, merged the
  broader year range in (188 is now 1970–1980), then deleted 186.

**Left unresolved / not acted on:**
- Cranksets: this catalogue's Ref.31.2 "ZEUS CICLO-CROSS" (single ring +
  integral guard, 970g) does **not** match the existing "Zeus Criterium w/
  'Ciclo-Cross' Chaingaurd" row (id 2027, double ring + add-on guard, 848g)
  or the Gran Sport equivalent (id 2030, 856g) — left all three alone as
  likely-different SKUs rather than guessing a merge.
- Recambios R-prefixed spares referencing other brands' resold parts (R.320
  Iris chain, R.516 Arius saddle, R.821–826 Akront rims, R.861 Michelin
  tubular) were left out of the Zeus brand entirely — one-line mentions only,
  no despiece, and not Zeus's own product.

## Catálogo Zeus-101 (Abadiano, 1970) — recordandobicicletaszeus.blogspot.com scan, data_source id 107

Same Section 2 "Componentes" structure and Ref numbering as Catálogo 102
(1973, see above) — this earlier printing was processed second, so the job
was mostly cross-catalogue weight reconciliation and pushing `year_from`
back to 1970 where this catalogue is earlier than what 102 alone had
established. No despiece content outside what's listed below; tools,
dropouts, fasteners and clothing sections are out of scope exactly as for
102.

**Confirmed an existing untracked attribution:** the Gran Sport pedal (id
4057) already carried a "440 grams (Spec), zeus catalog 101 (1970)" note
from before this skill tracked provenance — this catalogue's own Ref.41
page gives exactly 440g, confirming that old note was correctly attributed
all along.

**year_from pushed back to 1970** (this catalogue is earlier than the
DB's/102's existing value, weights otherwise matching): 4864 Alfa Junior
rear mech (240g both), 3171 Gran Sport headset, 3651 Gigante road hub (590g
both), 3652 Pista hub (590g both — now confirmed in *two* independent
catalogues, so the Gigante/Pista equal-weight coincidence is real, not a
scan artifact), 6392 Alloy Track Cog (12g both), 2026 Criterium triple
crankset.

**Cross-catalogue weight deltas kept as separate attributed figures** (not
overwritten — per-printing running changes, not noise): 4870 Criterium 69
rear mech (240g/1970 vs 220g/1973), 2681 Criterium 69 front mech (140g/1970
vs 130g/1973), 2026 Criterium triple crankset (997g/1970 vs 990g/1973), 4056
Pista pedal (410g/1970 vs 320g/1973 vs an older unlabeled 380g note), 3171
Gran Sport headset (190g/1970 vs 188g/1973), 8146 Standard hub (**530g/1970
vs 480g/1973** — the biggest single-printing delta found so far), 1181
Super Alfa 71 caliper (190g/1970 vs 177g/1973 — this row had no description
at all before this pass).

**New row inserted** (source_ref 107): Seat Posts "Zeus Ideale" (id 8151,
Ref.54, 180mm, 282g) — a rim-rail-saddle swan-neck seatpost sold alongside
the rod-rail "Zeus Criterium" seatpost; not present in the 1973 catalogue's
listing at all, genuinely missing before this pass.

**Left unresolved:** same Ciclo-Cross crankset non-match as noted under
Catálogo 102 above (this catalogue's Ref.31.2 is single-ring, 970g, still
doesn't match the existing double-ring "w/ Ciclo-Cross Chainguard" rows).
