## Spécialités T.A. product catalogue (28 pages, undated c. 1975, Reminiscence Part 53) — data_source id 206

- `data_source` 206, label "Spécialités TA catalogue (c. 1975)". Source:
  http://cyclespeugeot.web.fc2.com/reminiscence/ta70s.html, JPGs
  `catalog/ta70s/page-0001 to 0028.jpg`. **Only 360 x 510 px, no larger
  version on the server** (the `l` variants redirect); read after a 3x upscale,
  so large part numbers are reliable and fine print (weights, tooth ranges,
  thread codes, set numbers) is not. French / English, distributor TEVANO,
  printed in France. The site dates it "around 1975 because the pedal was
  introduced in the catalog"; nothing on the pages gives a year, so every
  row it touched is dated 1975 as a first-appearance year, not a start year.
  Index: pedals 2-3, headset 4, axles and cups 5, Professionnel 3-arm 6-7,
  Critérium 5-bolt 8-9, Cyclotouriste 5-bolt 10-11, Professionnel adapter
  system 12-13, single chainrings 14, tandem 15, then accessories (saddle
  tyre bag 273, bags 270-272, bottle cages 215 / 217 / 417 / 216, bottles
  147 / 177 / 197 / 200 / 202, shoe cleats 33-42, seat clamps 365 / 368,
  guide 32) and tools (greases 116 / 283, tool roll 1898, keys, extractor
  138): out of scope, no category. No prices. No part of the catalogue was
  missing.
