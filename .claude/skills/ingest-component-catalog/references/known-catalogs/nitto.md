# Nitto catalogs processed so far

## Nitto Handle Works catalogue No. 6 (1980) — cyclespeugeot.web.fc2.com, data_source id 158

- Source: http://cyclespeugeot.web.fc2.com/reminiscence/nitto80.html ("The
  Catalog of Reminiscence" part 26, Mr. Gami). 8 two-page spreads
  nitto80_01..08.jpg at only 720x509: model codes and dimensions legible,
  weight digits often not, so weights are written "c." (ranges). Cover "NO. 6",
  back "1980.9 Printed in Japan". Nitto Handle Works Co., Ltd., 4-41-2
  Arakawa-ku, Tokyo. English captions except the roadster bar (p. 15).
- Contents: drop bars (Mod. 155/165/175/185/55, Universiade B104/B105,
  Randonneur B132/B135, Olympiade B111-B115, Craft B123/B123AA/B125AA track,
  NJS mark), flat / upright bars (All Rounder B201-B212, North Road B302,
  B303, B307, B409, B417, Promenade B601-B603), stems (N.J. Pro / N.J. Pro AA
  = Nitto Jaguar Professional, Keirin reversible, Slider, Crystem, Pearl,
  Dynamic, Technomic, Young, Postem 35/50/70/U, Minitem, S 30), BMX (MX-1,
  MX-2 stems; B701, B702, B704V bars), seat posts SP-1/2/3, children's B502,
  B503, S25. Out of scope: Campee carriers, M3/M5 front carriers, Postem and
  tandem lugs, cycle stands, LP (La Prealpina) roof / ski carriers, the
  unnumbered steel / alloy / stainless seat posts and the rod-brake
  "gentleman" roadster bar (no model number).
- Titles: "Nitto <code>, <range name>" (Mod. NNN have no range name).
  Steel / AA / SL (18-8 stainless) variants of one code share one row, the
  variant weights in the description.
- All prior Nitto rows (brand 323) were bare velobase (source_ref 1).
- Retitled (old titles): 2876 "Nitto 115" -> Nitto B115, Olympiade (velobase
  "330 grams (Actual), for 42cm bars" kept as 330g actual; the catalogue has
  no 420mm width); 2877 "Nitto 165" -> Nitto Mod. 165 (1980-1985); 2878
  "Nitto Mod 55" -> Nitto Mod. 55 (1973 -> 1973-1980, velobase 320g spec kept
  since the scan weight is illegible); 2889 "Nitto Universiade 105" -> Nitto
  B105, Universiade (1980-1985); 2881 "Nitto B123AA, NJS Approved Track" ->
  Nitto B123AA, Craft (1980-2000 kept); 6606 "Nitto Racing Stem Reversible
  Type" -> Nitto Keirin, Reversible Type (1970 -> 1970-1980; 6607 "(early
  version)" untouched). Description only: 6612 Crystem (NULL -> 1980), 6621
  Pearl.
- year_to 1985 on 2877 / 2889 / 8563 comes from the 1985 Bianchi catalogue
  (Campionissimo / Squadra / Bambina specs), not from this one.
- New (48 rows, 1980-1980 except 8563 Technomic 1980-1985): bars 8529 Mod.
  155, 8530 Mod. 175, 8531 Mod. 185, 8532 B104 Universiade, 8533 B132 and
  8534 B135 Randonneur, 8535-8538 B111-B114 Olympiade, 8539 B123 Craft
  (steel), 8540 B125AA Craft, 8541-8545 B201 / B206 / B209 / B211 / B212 All
  Rounder, 8546 B302 North Road, 8547 B303, 8548 B307, 8549 B409, 8550 B417,
  8551-8553 B601-B603 Promenade, 8554-8556 B701 / B702 / B704V BMX, 8557 /
  8558 B502 / B503 Children; stems 8559 N.J. Pro, 8560 N.J. Pro AA, 8561
  Slider, 8562 Dynamic, 8563 Technomic, 8564 Young, 8565-8568 Postem 35 / 50
  / 70 / U, 8569 Minitem, 8570 S 30, 8571 S25 Children, 8572 MX-1, 8573 MX-2;
  seat posts 8574-8576 SP-1 / SP-2 / SP-3.
- Left alone: 6617 "Nitto Jaguar (steel)" (velobase 2000, 420g) — may be a
  later N.J. Pro but the weight doesn't fit (470-560g), so N.J. Pro is its own
  row; 6614 "Dynamic II" (presumably later than the plain Dynamic); 6613
  Crystemblue; rows absent from this catalogue (ADB 125 AA, aero / Tsubasa
  bars, M196, later stems, the 65 / 66 / 67 / 72 / Jaguar / S-83 posts).
- Unresolved: weights are approximate throughout; a higher-resolution copy
  of No. 6 would firm them up. B125AA's widths / drop / reach are also read
  approximately.

## Nitto Handle Works catalogue No. 11 (1989) — cyclespeugeot.web.fc2.com, data_source id 159

- Source: http://cyclespeugeot.web.fc2.com/reminiscence/nitto_handle1989.html
  ("The Catalog of Reminiscence" part 101). 22 pp + covers,
  nitto89_00..24.jpg at 720px single pages — fully legible, English. Cover
  "NO.11", back "1989.9. Printed in Japan". Sections: 90-degree stems, MTB,
  aerodynamics, track (Craft, N.J. Pro), road, flat / up bars, Postem,
  tandem, seat pillar, BMX, triathlon, touring (Randonneur), ZAO, cycle
  stand, Campee. Out of scope: expander bolt / wedge, handle tool, DH bar
  connector, ZAO bag and ZL-I / ZL-III racks, cycle stands, Campee, Postem
  lugs L35 / L50 / L60 / L70 / L-U.
- Supersedes the No. 6 (1980) low-resolution readings: where a No. 6 figure
  conflicted, the 1989 figure was taken as correct (treated as a misread)
  unless it was plainly a range change, which the description names by
  edition. Likely 1980 misreads corrected: Mod. 185 reach (c. 87 -> 82),
  B123 reach (100 -> 108), B201 width (c. 560 -> 500), B206 width (595 ->
  525), B307 width (405 -> 435), B409 raise (c. 65 -> 98), B602 / B603
  dimensions. B105 drop (125 in 1980, 135 in 1989) is kept as two figures.
- Updated to year_to 1989 with 1989 specs (41 rows): bars 2889 B105, 2876
  B115, 8536 B112, 8529 Mod. 155, 8531 Mod. 185, 2878 Mod. 55, 8539 B123,
  2881 B123AA (1980-2000 kept), 8540 B125AA, 8533 B132, 8534 B135, 8541 B201,
  8542 B206, 8546 B302, 8548 B307, 8549 B409, 8550 B417, 8551-8553 B601 /

  Pro / AA, 6621 Pearl, 8563 Technomic (NTC / NTC-225 / NTC-280 in one row),

  Crystemblue" -> Nitto Crystem Blue (1980-1990 kept); 6614 "Nitto Dynamic
  II" -> Nitto Dynamic-2 (NULL -> 1989; the 90-degree stem, kept separate
  from the 1980 Dynamic 8562); 6612 "Nitto Crystem" -> Nitto N65, Crystal

- Merged / deleted: 6620 "NITTO 65" (stem, velobase, no years, source_id
  2A181073-F20C-40BC-BF8D-5ADBE3776C72, no bike links or overrides) into
  6612 — "Crystem" = Crystal Stem, model code N65.
- New (59 rows, 1989-1989 except 8622 B110AA 1985-1989 from the 1985 Bianchi
  Bambina "Nitto Junior, 340 mm" link): stems 8577 CR-52 DB / BB (Dull- /

  B123CrMo-BT New Craft, 8616 B125 Steel, 8617 B65LL, 8618 Mod. 185-H, 8619
  B88-H, 8620 B105-RD, 8621 B105-LD, 8622 B110AA, 8623 NTR55, 8624 Clip On

- In No. 6 but not No. 11 (year_to stays 1980): Mod. 165 / 175, B104,
