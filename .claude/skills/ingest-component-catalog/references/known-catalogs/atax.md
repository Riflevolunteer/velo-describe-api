# ATAX / Philippe catalogs processed so far

## ATAX / Guidons Philippe catalogue (1982) — classicrendezvous.com, data_source id 157

- Source: https://classicrendezvous.com/country-of-origin/france/french-parts/atax-philippe/atax-1982-catelog/
  (13 images atax_1..13.jpg, ~580x768 — small but legible). ATAX S.A., 30
  rue Orsel, 69600 Oullins (Rhône), "Distributeur Guidons Philippe".
  French / English, weights and dimensions, no prices. Undated in itself;
  1982 is the page title. Pp. 3-8 ATAX stems, p. 8 seat pillar, pp. 9-11
  Philippe bends, p. 12 tools / expanders (out of scope).
- Brands: ATAX (306) for stems and the seat pillar, Philippe (325) for bends
  (the catalogue brands them "Guidons Philippe"). All 37 prior rows were bare
  velobase.
- Bend codes: A = steel, D = /1 dural, DG = /2 dural engraved, /3 dural
  engraved silver anodised. Titles use "Philippe <name> <base ref>" and put
  the variant codes in the description, so search_text stays clean.
- NOUVEAUTÉ: ASC aero stem, PSCM stem with lever support, seat pillar.
- Retitled (old titles): 2899 "Philippe Olympic D350 (later ATAX version)"
  -> Olympic 350 (...); 2895 "Philippe Professionnel" -> Professionnel 351
  (1970 -> 1970-1982; 2896 "(later version)", velobase 1950, untouched);
  2897 "Philippe Franco Italia D 352" -> Franco Italia 352 (1980 -> 1982);
  2900 "Philippe Competition D353" -> Competition 353; 2901 "Philippe Franco
  Belge" -> Franco Belge 354; 2902 "Philippe Tour de France D357" -> Tour de
  France 357; 2891 "Philippe Franco America" -> Franco-Americain 358 (velobase
  370g kept beside the 340g spec); 2894 "Philippe Pista (steel)" -> Piste
  americain A 356 (steel) — judgment call, the only steel track bend; 6450
  "ATAX (with shifter bosses)" -> PSCM 75 / 90 / 105 (with lever support),
  year_from 1980 kept despite NOUVEAUTÉ. NULL-year rows -> 1982-1982.
- New (29 rows, 1982-1982): bends 8500 Randonneur 355, 8501 Tessinois 301 /
  302, 8502 Helvetia 303 / 304, 8503 Porteur 305 / 306, 8504 Porteur Anglais
  307 / 308, 8505 Trials plats 309 / 310, 8506 Trials relevé 311 / 312; stems
  8507-8527 (ASC, PSC, PSCE, PSCL, PSCEL, CFC / CFCG, PE child, PO 613 / 615,
  PUM, PUM X, PA, PAX, PO / PR 66, POC, PR / PRC 67, PSC 99 / PVC 71, PU 57 /
  74, PS / PSC 72-78, No. 16 piste aero, PH 37 piste à glissière, No. 62
  piste plongeante), one row per family; 8528 ATAX alloy seat pillar.
- Bike links (from the 1979 Peugeot catalogue, a different source): 24 Peugeot
  1979 bar specs linked via Handlebars overrides — "Course" / "Course type" /
  "Course, dural" / "Dural course" / "Steel course" / "Atax course, dural" ->
  2901 Franco Belge 354 (the catalogue's only "Course" bend; only PX 10 C
  names ATAX, the rest are inferred from the bend name), "Helvetia type"
  variants -> 8502, "Randonneur bend" -> 8500. year_from moved 1982 -> 1979
  on 2901, 8502, 8500 to cover them. "Course front, Tessinois rear" (TM 8 /
  TH 8 tandems) left unlinked — one spec, two bars.
- Left: ATAX stems 6447 (1A style, linked to two 1979 Peugeots), 6448 / 6449
  aero XA (possibly ASC or CFC), 6451-6455; ATAX CTA bars 2782-2784; Philippe
  2898 Olympic earlier version, 2892 / 2893 Pista, 2903 Randonneur small
  (maybe a narrow 355), all Philippe stems (6628 track adjustable may be an
